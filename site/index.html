Ask a codebase anything. Check every answer.

SpectraCode indexes a repository and answers questions about it. Each answer cites the exact file and lines it came from, and every citation is checked against the source before you see it.

How an answer gets checked

  1. Parse

    Each file is split along function, method and class boundaries, so a span is always a whole unit with exact line numbers.

  2. Search

    A meaning-based search and an identifier-aware keyword search each rank the spans. The two rankings are merged.

  3. Follow

    Functions and types that the top spans refer to are looked up one hop away and added as context.

  4. Answer

    The model writes its answer and cites spans by file and line range.

  5. Check

    Every citation is compared with the retrieved code. Lines out of range are adjusted, unknown files are rejected, and unsupported questions get no answer.

Run it on your machine

You need Python and Node.js. No Docker and no API key are required to start.

1 Start the backend

git clone https://github.com/YahyaLendani/SpectraCode.git
cd SpectraCode/backend
python -m venv .venv
# PowerShell: .\.venv\Scripts\Activate.ps1  |  Unix: source .venv/bin/activate
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload --port 8000

2 Start the frontend

cd SpectraCode/frontend
npm install
npm run dev

Then open http://localhost:3000. On first start the backend indexes a small FastAPI sample repository, so there is something to ask about straight away. It reads Python, TypeScript, TSX and JavaScript, and search embeddings are computed on your machine.
